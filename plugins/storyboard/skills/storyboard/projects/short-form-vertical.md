# Short-Form Vertical (Social)

**Goal:** Stop the scroll and land exactly one idea, for an audience that did not choose to watch this.

**Audience:** `skye` (social scroller) first and foremost, plus `yoan` (young adult) and `theo` (teenager) depending on placement. `dev` and `nadia` matter more here than in any other format, because burned-in captions are the primary channel for everyone, not an accommodation.

**Key message:** One. Not a main message with supporting points — one.

**Tone:** Direct, fast, unpolished enough to feel native to the feed rather than like an ad that wandered in.

## Story structure (default)

**in medias res** — the first two seconds decide everything; there is no time to establish anything before the hook.

Sasha Script can deviate, but says so in the brief and says why. The beat breakdown below is this structure's stages named for this format; changing the structure changes the beats.

## Beat breakdown

| Time | Beat | What happens |
|---|---|---|
| 0:00–0:02 | Thumb-stop | A legible-without-sound visual or text hook. This beat is the entire piece's success condition — everything after it only matters if this works. |
| 0:02–0:08 | Problem | The recognizable pain, stated in one line of on-screen text plus visual. |
| 0:08–0:16 | Payoff | The one idea, shown rather than explained. |
| 0:16–0:20 | CTA | Where to go, on screen long enough to read and act on. |

## Team for this project

- **Sasha Script (scriptwriter)** — writes for on-screen text first, VO second; the text version has to carry the whole thing alone.
- **Dana Director (director)** — ruthless about the two-second hook; everything else is negotiable.
- **Stella Storyboard (storyboard artist)** — boards for 9:16 from the start; this is not a cropped 16:9 piece.
- **Arthur Art (art director)** — owns caption legibility and safe zones, including the platform UI overlays that eat the bottom third.
- **Ed Edit (editor)** — cuts faster than feels comfortable; social pacing is not corporate pacing.
- **Sonny Sound (sound designer)** — designs assuming nobody hears it, then makes it good for the minority who do.
- **Molly Motion (motion lead)** — usually active; this format is mostly kinetic type and UI motion.
- **Paul Producer (producer)** — fast turnaround, low budget, high volume; this format only works if it's cheap to make.

## Deliverables checklist

- [ ] Locked script (on-screen text version *and* VO version)
- [ ] Approved 9:16 boards
- [ ] Burned-in captions, legibility-checked at phone size
- [ ] Safe-zone check against target platform UI
- [ ] Sign-off

## Constraints specific to this project

- Assume sound off and no prior context whatsoever — this viewer does not know who you are.
- Platform UI covers the bottom ~15% and the right edge; nothing meaningful goes there.
- Burned-in captions are mandatory, not optional — the format is unusable without them for a large share of the audience.
- If it needs more than one idea, it's the wrong format. Make a longer piece and cut this from it via **Time Reduction**.
