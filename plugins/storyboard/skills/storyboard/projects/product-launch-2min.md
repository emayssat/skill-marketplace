# 2-Minute Product Launch

**Goal:** Announce a shipped (or shipping) product/feature and convert awareness into trial or adoption.

**Audience:** Existing customers, prospects, press/analysts, and internal go-to-market teams who'll reuse the footage.

**Key message:** This specific, real thing is available now, it solves a concrete problem, and here's exactly how to get it.

**Tone:** Confident, concrete, faster-paced than a vision piece — this is proof, not promise.

## Story structure (default)

**problem → agitate → solve** — the audience already feels the pain, so naming it buys credibility before the product appears.

Scott Script can deviate, but says so in the brief and says why. The beat breakdown below is this structure's stages named for this format; changing the structure changes the beats.

## Beat breakdown

| Time | Beat | What happens |
|---|---|---|
| 0:00–0:10 | Hook | Bold claim or a sharp "before" moment — something the audience recognizes immediately. |
| 0:10–0:30 | Problem | Name the gap in the market or the pain today, fast — no more than 2 lines of narration. |
| 0:30–1:10 | Reveal / demo | The product itself, shown doing the real thing — actual UI or actual product, not a mockup. This is the proof section. |
| 1:10–1:40 | Differentiation | Why this matters vs. the alternative — a stat, a customer quote, or a direct before/after. |
| 1:40–2:00 | CTA | Availability, pricing/tier if relevant, and the exact next step with a URL or date on screen. |

## Team for this project

- **Scriptwriter** — writes tight, claim-driven copy; every line has to survive legal/PR review, so revisions are expected.
- **Director** — keeps the demo section from turning into a feature tour; one clear proof beat, not five.
- **Storyboard artist** — boards real screens/product footage plans, tight on actual UI accuracy since this ships publicly.
- **Art director / Production designer** — ensures brand compliance (logo, color, type) is correct for an external-facing asset.
- **Cinematographer / Director of Photography (DP)** — fully active if there's any live-action (customer testimonial, spokesperson, b-roll); coordinates screen-capture quality if not.
- **Editor** — drives pace; this format is judged on watch-through rate, so the cut has to earn every second.
- **Producer** — owns the hard external deadline (launch day) and coordinates with PR/marketing on release timing.
- **Client / stakeholder** — product marketing and/or legal; sign-off is a hard gate here since this goes public.

## Deliverables checklist

## Constraints specific to this project

- Hard, external launch-day deadline — schedule works backward from that date, not forward from kickoff.
- Every claim shown or spoken must be verifiable and cleared by legal/PR before publish.
- Must work with sound off (captions/on-screen text) since it'll run on social autoplay.
